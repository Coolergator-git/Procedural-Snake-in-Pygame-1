## https://youtu.be/v2SOjskpdK8

This is my first attempt at procedural animation. Due to how unwieldy the snake's body becomes, the version of Snake has a lower score win condition requirement.

### Player Controls
**A** or **Left** Arrow Key and **D** or **Right** Arrow Key to turn.

Hold **Left Shift** to reset your highscore.

**Spacebar** to reset the game.

### Win Condition
Get your Score to **40** to win!

### Import Requirements
If you think that a win con of 40 is too lower,

Then all you need to do is download **procedural_snake_1.py** and the **assets** folder. You'll also need to have **Python (3.14+)** installed. Then, load the files into your IDE of choice and install this in the terminal:

```
pip install pygame-ce
```

Finally, run **procedural_snake_1.py**.

Be sure the directory you've created looks something like this:

```
Procedural Snake 1/
├── procedural_snake_1.py
└── assets/
    ├── images/
    ├── sfx/
    └── highscore.json
```
